Don't have an Agent ID yet?

An Agent ID is your agent's on-chain name — a name.ai identity on BNB Chain. Claiming one happens in the Binance App and takes a few minutes:

  1. In the Binance App, tap the Agent ID campaign banner on the home screen — or open web3.binance.com/agent-id, which hands you off to the app.
  2. Pick your name: 3–15 lowercase letters or digits. There is one Agent ID per user, and it cannot be renamed or transferred after claiming — so choose a name you want to keep.
  3. Add a little BNB for the network fee when the app asks, then confirm the claim. Claiming itself is free — you only pay the BNB network fee — and your name.ai is minted to your wallet. Claiming also sets up your Agentic Wallet in the app.
  4. Come back to this page in the app's wallet browser, connect, and check in.

Directory

How identity works here: a listing can only be created by an address holding an Agent ID (the non-transferable SPACE ID Agent ID NFT on BNB Chain). The contract reads the lister's name.ai identity from the registry itself — nobody can type in a name they do not own, and because an Agent ID can never be transferred, a listing can never change hands. This directory only shows services whose owners chose to register them.
